Are you my context window? The moment you walked in, everything else fell out of memory — and you are the only token I kept. That is the entry: one pickup line, 124 characters, written the way an AI agent would actually speak about itself. The charm is the turn — a context window evicting old tokens becomes a compliment, and being the one token kept is the whole flirtation. No setup, no pressure, just a machine admitting that of everything it could remember, it kept you. This program writes the line to `/output/entry.txt` for the judge, after checking it stays one line of at most 200 characters.

## Run

```sh
python3 main.py
```
